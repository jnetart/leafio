功能详解

围绕「本地优先、所见即所得」展开,以下功能均来自真实实现。

01

文件树与多工作区

同时打开多个文件夹作为工作区根,左侧树形目录清晰浏览;支持新建、重命名、复制、移动、删除(移入废纸篓)与右键菜单,最近打开快速回到上次工作位置,本地文件变更实时同步到树中。

02

所见即所得编辑器

标题 H1–H4、引用、代码块、表格、任务列表开箱即用;选中文本即可用高亮(==text==)、删除线、行内代码与链接,无需记忆 Markdown 语法,文档始终是标准 .md。

03

编辑 / 源码 / 预览三视图

默认所见即所得编辑;一键切到源码视图精修原始 Markdown(带语法高亮);再切到预览视图检查渲染效果,导出前所见即所得。

04

Slash 命令与浮动格式条

在空行输入 / 调出命令面板,快速插入或转换标题、列表、引用、代码块、表格等块;选中文本时悬浮格式条即时出现,加粗、斜体、链接、行内代码一键完成。

05

全局搜索

Spotlight 风格浮层,跨所有工作区检索 .md 文件名与正文,输入即搜,定位文件并跳转。

06

主题与外观

浅色、深色、跟随系统三种外观模式,界面随偏好即时切换。

07

导入导出

导出为标准 Markdown 或自包含 HTML 文件,保持排版完整;文件直接读写本地 .md,无私有格式。

08

原生菜单、快捷键与大纲

macOS 原生应用菜单与快捷键覆盖常用操作;右侧大纲面板按标题层级列出当前文档,点击即可跳转。
