使用指南

从打开工作区到导出文档,下面的步骤带你快速上手 Leafio。

工作区管理

在欢迎窗口点击「打开文件夹」,把任意本地文件夹作为工作区,也可以打开单个 .md 文件。左侧文件树支持新建、重命名、复制、移动、删除(移入废纸篓),右键菜单提供常用操作,本地文件变更实时同步。

编辑方式

直接输入即可写作:标题(1–4 级)、引用、代码块、表格、任务列表都以语义块呈现;选中文本可应用高亮(==text==)、删除线、行内代码与链接。在空行输入 / 打开命令面板快速插入块,选中文本时弹出浮动格式条。

三视图

工具栏的分段控件切换三种视图:编辑(所见即所得,默认)、源码(原始 Markdown,带语法高亮)、预览(渲染后的只读视图)。

搜索

使用查找(⌘F)打开 Spotlight 风格搜索浮层,跨所有工作区检索 .md 文件名与正文。可用 tag:会议、path:notes 过滤,匹配片段会高亮,↑↓ 选择后回车打开。

主题

在设置中选择外观模式:浅色、深色或跟随系统,界面即时切换并记住偏好。

导入导出

使用导出(⌘⇧E)将当前文档导出为标准 Markdown 或自包含 HTML。文件直接读写本地 .md,无私有格式,可配合 Git 与同步盘使用。
