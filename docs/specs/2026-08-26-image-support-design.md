# 图片支持（第一版）

日期：2026-08-26  
状态：已确认设计，待写实现计划

Leafio 当前 schema 没有 Image 节点，Markdown 里的 `![]()` 解析时被丢掉。第一版补上本地图片：拖入 / 粘贴 / 斜杠插入，复制到笔记旁的资源夹，相对路径写入 Markdown，编辑和预览可点开放大，可选压缩，编辑里可设显示宽度。

## 目标与非目标

### 目标

- 技术文档和笔记可以在正文中放截图、示意图。
- 文件留在工作区磁盘上，Git 能跟踪；Markdown 用相对路径。
- 编辑视图和预览视图所见即所得；源码视图能往返显示尺寸。

### 非目标（第一版不做）

- PDF、zip 等通用附件
- 大纲里列出或预览图片
- 图床 / 远程上传
- 删除图块时清理磁盘上的文件
- 导出 HTML 时打包 `*.assets`
- 裁剪、旋转、标注
- 独立于 `alt` 的可见图注

## 落盘

对笔记 `{dir}/{stem}.md`，导入的图片写到：

```
{dir}/{stem}.assets/{filename}
```

Markdown 中的路径为 `./{stem}.assets/{filename}`，例如：

```markdown
![架构](./api-guide.assets/architecture.png)
```

规则：

- 资源夹与笔记同目录，不集中到工作区根或 `~/Documents/leafio/assets/`。
- 用户打开任意文件夹作为工作区时，规则不变：始终相对**当前笔记文件**。
- 文件树隐藏名称以 `.assets` 结尾的文件夹（大小写不敏感）。图片文件本来就不显示。
- 保留已有文档里的 `![](./shot.png)` 或 `![](https://…)`，不强制搬进 `*.assets`。
- 去掉图块时**不删除**磁盘文件（撤销只需去掉节点）。空的 `*.assets` 也先留着。

### 文件名

- 从访达 / 选文件导入：尽量保留原名；去掉路径分隔符；不能为空。
- 重名：`file.png`、`file-1.png`、`file-2.png`。
- 剪贴板位图没有文件名：`pasted-YYYYMMDD-HHMMSS.png`（类型按实际编码，一般为 png）。

## 节点与 Markdown

块级 `image` 节点（`inline: false`），属性：

| 属性 | 含义 |
| --- | --- |
| `src` | Markdown 中的路径（相对或 `https://`） |
| `alt` | 替代文字，默认为空字符串 |
| `width` | 显示宽度（CSS 像素整数）。仅用户拖过宽度时有值，否则为 `null` |

编辑器和预览共用该节点。源码视图仍是纯文本。

### 解析

- 单独成段的 `![alt](src)` → 一个 `image` 块。
- HTML `<img src alt width>` → 一个 `image` 块；有合法正整数 `width` 则写入属性。
- 夹在文字中间的图拆成相邻块（文字 / 图 / 文字），第一版不保留行内图节点。打开并保存这类旧文档时，源码会变成图单独成段；接受这个变化。

### 序列化

- `width == null`：`![alt](src)`，前后按普通块级空行处理。
- `width` 有值：`<img src="..." alt="..." width="480">`（不要 `style`，不要 `height`，保持比例由渲染端计算）。

这与现有「普通表格走 Markdown、带背景才降成 HTML」的策略一致。

## 导入

模块 `ingestImage(notePath, source)` 是唯一写入入口。来源：拖入文件、剪贴板、斜杠命令选文件。

1. 校验为支持的图片，否则不插入。
2. 若设置开启压缩且格式允许，按最长边缩放后再写。
3. 确保 `{stem}.assets/` 存在。
4. 复制或写入目标文件。
5. 返回 `./{stem}.assets/{filename}`，由编辑器在落点插入 `image` 块。

### 支持的类型

`png`、`jpg`、`jpeg`、`gif`、`webp`、`svg`。其他类型（含 heic、pdf）拒绝。

### 体积

单张超过 25MB 拒绝。压缩在校验体积**之后**、写入之前；压缩后仍超过则拒绝。

### 压缩（设置，默认关）

偏好设置（编辑器分组）：

- `compressImages: boolean`，默认 `false`
- `compressMaxEdge: number`，默认 `1920`（最长边像素）

只影响**新导入**。svg、gif 不压缩（矢量 / 动画）。压缩失败则保存原图，并提示「已保存原图」。

### 远程地址

已有或粘贴的 `https://` 图：只把 `src` 写成该 URL，不下载。拖入本地文件才复制进 `*.assets`。

从浏览器复制时：优先剪贴板里的图片文件或 data URL，走 `ingestImage`；只有纯 URL 时才插入远程 `src`。

### 落点

用现有块间隙和 dropcursor 指示位置，不要全屏虚线投放框。

选区在表格单元格内时，把图插在**该表格后面**（单元格只容纳段落，不能放块级图）。

一次拖入多张：按顺序插入多个块。

## 显示与交互

图本身没有卡片壳。未选中：按栏宽渲染；若有 `width` 则用该像素宽度，且 `max-width: 100%`。未选中不显示边框、工具条、图注。

选中后：

- 左右拖边改宽度，锁定宽高比；最小 80px，最大为当前编辑栏内宽。
- 下方一行「添加说明」，写入 `alt`。未选中时不把 `alt` 画成图注。
- 「原始宽度」或双击拖边：将 `width` 置为 `null`，源码回到 `![]()`。

点图片（不是拖边）在**编辑**和**预览**打开灯箱：纸面变暗，图按原始像素居中（超出窗口则contain），点空白或 Esc 关闭。源码模式和大纲没有灯箱。大纲仍然只列标题。

斜杠命令「图片」（insert 分组，关键词含 `image`、`img`、`图片`）打开系统文件选择，可多选。

从另一篇 Leafio 笔记粘贴图块：若源文件还在，复制进当前 `*.assets/` 并改 `src`。

坏图：显示 `src` 和「文件不存在」。本地路径提供「在文件夹中显示」；`https://` 失败则没有该按钮。

## 笔记生命周期

| 操作 | 资源夹 |
| --- | --- |
| 重命名 `old.md` → `new.md` | `old.assets` 重命名为 `new.assets`；正文里 `./old.assets/` 换成 `./new.assets/` |
| 移动笔记 | `*.assets` 一起移动；若相对路径仍是 `./stem.assets/…` 则不必改 src |
| 删除笔记（进废纸篓） | 同名 `*.assets` 一起进废纸篓 |
| 复制笔记 | 复制 `*.assets`，并保证副本正文仍指向新 stem 的资源夹 |

## 架构

```
拖入 / 粘贴 / 斜杠
        ↓
  ingestImage(notePath)
        ↓
  Tauri 二进制写入或复制 → {stem}.assets/
        ↓
  插入 image 块（src 为相对路径）
        ↓
  NodeView：相对路径 + notePath → 绝对路径 → convertFileSrc → <img>
        ↓
  保存：serializeMarkdown → ![]() 或 <img width>
```

- `Editor` / `PreviewView` 增加 `notePath`。未打开文件时没有编辑器，粘贴时一定有路径。
- Rust 增加二进制写入和按目标路径复制（现有 `write_file` 只接受字符串；现有 `copy_file` 只做 Markdown 副本）。
- 本地预览走 Tauri `convertFileSrc`；需要允许工作区文件的 asset 协议。
- 设置项并入现有 `AppPreferences`，中英两套文案。

显示用 `<img src>` 加载 svg，不把 svg 内联进文档。

## 失败与文案

| 情况 | 行为 | 文案 |
| --- | --- | --- |
| 非图片 | 不插入 | 只支持图片 |
| 超过 25MB | 不插入 | 图片过大 |
| 磁盘写入失败 | 不插入 | 无法保存图片 |
| 压缩失败 | 写入原图 | 已保存原图 |
| 本地文件缺失 | 占位 | 文件不存在 |
| 远程图加载失败 | 占位 | 文件不存在 |

状态栏短句，不弹模态框。

## 测试

自动化：

- `parseMarkdown` / `serializeMarkdown`：无宽度 `![]()`、有宽度 `<img>`、往返后属性一致。
- 路径：`stem.assets` 相对路径、重名后缀、重命名时正文替换。
- 文件树：`*.assets` 不出现。
- 斜杠命令能匹配「图片」/ `image`。

手动：拖入、粘贴截图、斜杠选文件、拖宽度后切源码再切回、灯箱、坏图占位、重命名笔记后面图仍在。不强制用 Playwright 模拟系统拖放。

## 视觉

签名只有一处：图先当栏内印刷品，选中才出现拖边和说明行。投放只用块间隙线，不用虚线大框。灯箱是纸面变暗，不是黑色影院全屏播放器。颜色、字体、圆角跟现有编辑器（代码块壳、浮动工具条）走，不另起一套媒体卡片风格。
